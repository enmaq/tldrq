# Contributing to tldrq

Thanks for your interest in tldrq.

## Source availability

tldrq source is closed. This repository hosts the public documentation, changelog, media, and community files — it does not contain the application source, so code contributions cannot be built or merged from public source here.

We open the source on request for a security review, an audit, or a customer who needs to see it, under a simple agreement. Write to **support@enmaq.com**.

## How to help

- **Bug reports:** use the bug report issue template. Include your tldrq version, operating system, terminal, and minimal steps to reproduce.
- **Feature requests:** use the feature request issue template. Describe the problem first, then the change you would like.
- **Documentation fixes:** pull requests for typos, broken links, and clarifications to the public docs in this repository are welcome — keep them focused.
- **Security issues:** do not file publicly; follow [SECURITY.md](SECURITY.md).

For anything else, contact **support@enmaq.com**.
